# 协同事务平台

协同事务平台为需要多机构参与的业务提供统一的机构、授权、案件、证据、审批、资源预约、资金分录、消息归并、通知、定时任务和历史回放能力。项目只使用 Python 标准库与 SQLite，适合在单个 Linux 应用容器内运行。

## 目录

- `src/civicflow/`：领域服务、SQLite 持久化、权限和命令行入口。
- `tests/`：核心流程、边界条件和异常路径测试。
- `examples/`：本地演示输入。

## 配置

通过 `CIVICFLOW_DB` 指定 SQLite 文件路径；不设置时命令行使用当前目录下的 `civicflow.sqlite3`。所有时间使用带时区的 ISO 8601 字符串。

## 测试

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## 编译或构建

```bash
PYTHONPATH=src python3 -m compileall -q src
```

## 使用

初始化数据库并运行离线演示：

```bash
PYTHONPATH=src python3 -m civicflow.cli --db /tmp/civicflow-demo.sqlite3 demo
```

查看当前案件：

```bash
PYTHONPATH=src python3 -m civicflow.cli --db /tmp/civicflow-demo.sqlite3 list-cases
```

## 园区服务结算（广州公铁联运枢纽高标仓）

`settlement.py` 在既有组织、预约、资金分录、凭证、审批、事件收件箱、审计链能力之上，建立从仓位租约到月台、冷库、充电、铁路接驳结算的完整依据。

```bash
PYTHONPATH=src python3 -m civicflow.cli --db /tmp/settlement-demo.sqlite3 settlement-demo
```

### 依据链（全部带有效期间）

- **仓位单元、交付验收、租约版本**：租约变更必须显式 `supersedes` 上一版本；新版本只关闭上一版本的未来区间，出账按费用窗口落在哪个版本就用哪个版本，历史账单不被改写。
- **设备计量点、服务目录、价格规则**：价格按 `valid_from` 分段，临时调价跨过账期时制冷费逐段取价；被取代的历史价格对历史窗口仍然有效。
- **维保停机、费用承担关系**：停机区间按小时从制冷费中扣减；运营方承担区间同样按重叠小时数扣减。
- **账期与费用**：每笔费用带 `window_start/window_end`、来源类型与来源号（租约版本/预约/原始读数/停机）、`price_id`、`lease_id+version`、审批号与结构化明细，可逐笔下钻。

### 三类申诉的处理规则

1. **冷库停机仍计费**：出账前登记的停机在生成费用时自动扣减，补偿任务到期只做确认、不重复退款；账期关账后补登记的停机（历史错收）由维保补偿任务在下一个未关账账期自动生成贷项。
2. **临时扩仓跨账期找不到价格**：价格、目录、租约都是分段有效期记录，出账时对每个费用窗口做 as-of 查询和按价格版本切段，任何时点都能找到当时适用的价目；已关账账期不允许重新生成，差错只能贷项/补单。
3. **拼单用量全落到一家**：月台、充电、铁路接驳按能力预约（容量冲突受控），跨租户作业必须逐户 `allocate` 实际数量且合计等于预约能力，出账按各户数量分别计费；设备故障只 `release_booking` 受影响的那一笔，底层占用同步释放。

### 防错与职责分离

- **抄表**：读数同时进入事件收件箱。同一计量编号同一时刻再次到达且读数一致 → 判重不重复入账；读数不一致 → 落争议表与收件箱冲突、发件箱通知，并暂停该账期结算，争议按原读数或新读数处理后恢复；读数倒退同样暂停。
- **减免审批**：提交人即使拥有审批权限也不能批准自己的申请（`assert_distinct`）；批准后自动生成贷项费用草稿。
- **租户边界**：租户上下文（`AccessContext.tenant_user`）只能读本企业费用，越界查询或下钻一律拒绝；关账人员凭 `settle:close` 可从费用下钻到占用/预约与拆量、原始读数、价目、租约版本、交付验收和批准人。
- **关账**：存在草稿费用或未决读数争议时禁止关账；关账后只能在后续开放账期开贷项（`issue_credit`）或补单（`issue_supplement`），纠正单据带 `parent_charge_id` 指回原费用。
- **进程重启**：缺抄表提醒、维保补偿、租约到期均为确定性编号的持久任务（`schedule_named`，重启后重复登记不会覆盖原期限），到期由 `run_due_jobs` 认领处理，无需人工重新登记。
- **审计**：登记、签约、停机、预约、拆量、抄表、出账、过账、关账、减免等动作全部追加到哈希链审计日志，`verify` 可校验连续性。

### 权限点

| 权限 | 用途 |
| --- | --- |
| `settle:admin` | 主数据、租约、停机、争议处理、到期任务认领 |
| `settle:book` | 能力预约与拼单拆量 |
| `settle:reading` | 设备读数录入 |
| `settle:bill` | 生成费用、过账、维保补偿 |
| `settle:relief` | 提交减免申请 |
| `settle:approve` | 审批减免、开贷项/补单（不得审批本人申请） |
| `settle:close` | 关账与费用下钻 |
| `settle:read` | 费用查询（受租户边界约束） |
